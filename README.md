# Prompt Engineering & AI Productivity Toolkit
**Module 02 | Day 6–Day 10 | Beginner Level**

## Project overview
This project demonstrates how to write clear prompts and use AI productively for:
- Zero-shot and few-shot prompting
- Roles, context, instructions and constraints
- Structured output (JSON)
- Summarization, classification and content generation
- AI-assisted coding and debugging
- Prompt evaluation with reusable tests
- Productivity workflows for email, resumes, research and coding

> The examples use Python functions and illustrative AI responses so the notebook can run without an API key. To connect a real AI model, replace the demonstration function with your provider's API call and keep your API key in a secure secret store (never commit it to GitHub).

## Getting started
1. Download or clone this repository.
2. Open the folder in VS Code or another Python editor.
3. (Optional) Create a virtual environment.
4. Install dependencies:
   `pip install -r requirements.txt`
5. Run:
   `python src/prompt_toolkit.py`

## Google Colab
Upload the supplied `Prompt_Engineering_AI_Productivity_Colab.ipynb` notebook to Google Colab, or open it from Google Drive. Run cells from top to bottom.

## Main learning outcomes
By completing this project, a learner can:
1. Differentiate zero-shot and few-shot prompting.
2. Write prompts with a role, context, task, format and constraints.
3. request structured JSON output and validate it.
4. Create prompts for summarization, classification and generation.
5. Use AI as a coding and debugging assistant while checking the result.
6. Evaluate prompts using a repeatable test checklist.
7. Build reusable workflows for everyday productivity.

## Important responsible-use notes
- Do not enter passwords, private student records or confidential company data.
- Verify facts, calculations, citations and code before using them.
- AI can make mistakes or produce biased or outdated answers.
- Keep a human review step for important decisions.
